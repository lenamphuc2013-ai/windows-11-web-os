=== HƯỚNG DẪN CÀI ĐẶT & CHẠY ===

--- Bước 1: Tải Node.js ---
1. Mở trình duyệt → vào trang: nodejs.org
2. Nhấn nút TẢI (phiên bản LTS - bản dài hạn ổn định nhất)
3. Tệp tải về → nhấp đúp để cài
4. Nhấn TIẾP THEO → TIẾP THEO → CÀI ĐẶT → XONG
→ Không thay đổi gì, cứ nhấn Tiếp theo là được!

--- Bước 2: Cài thư viện ---
1mở cửa sổ lệnh của node.js lên
2. Mở thư mục dự án 
3. nhập cd dẫn đến thư mục dự án
4. Gõ lệnh rồi nhấn Enter:
   npm install
→ Chờ nó chạy xong, tự tải tất cả thư viện cần thiết!
--- Bước 3: Khởi chạy máy chủ ---
1. Vẫn cửa sổ đó, gõ lệnh:
   npm run dev
2. Nó hiện ra link giống như: http://localhost: ...
3. Mở trình duyệt → gõ link đó → Nhấn Enter
→ Dự án chạy ngay! XONG!

--- Lưu ý ---
- Khi dùng xong: đóng cửa sổ CMD là tắt máy chủ
- Mỗi lần chạy lại: chỉ cần Bước 3 thôi!
